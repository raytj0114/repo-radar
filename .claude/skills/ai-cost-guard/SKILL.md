# AI Cost Guard

## 鉄則

AI呼び出し回数は**コンテンツ数**にのみ比例させる。ユーザー数・リクエスト数に比例させない。

## 実装チェックリスト（すべて必須）

1. **キャッシュファースト**: DBキャッシュを確認し、ヒットしたら即返す。Gemini呼び出しはミス時のみ
2. **cacheKeyは `src/lib/github/cache-key.ts` の関数で生成**する。文字列直書き禁止
3. **認証必須**: Server Actionの冒頭で `requireSession()`。cronは `CRON_SECRET` をBearer検証
4. **クライアントから制御フラグを受け取らない**: `skipCache` / `forceRegenerate` 等の引数をactionのシグネチャに含めない。再生成が必要ならサーバー側の管理用スクリプトとして実装
5. **プロンプトへの入力はサーバー取得データのみ**: クライアントから渡された文字列（リポジトリ名すら）を直接プロンプトへ埋め込まない。IDを受け取り、サーバーでGitHub APIから引き直す
6. **保存とセット**: 生成に成功したら必ずDBへ保存してから返す。保存失敗時は生成結果を返さない（キャッシュを迂回する経路を作らない）
7. **同時実行**: 同一cacheKeyへの並行生成はupsertで最後の書き込み勝ちとし、エラーにしない

## エラー時のユーザー向けメッセージ

- 429: 「しばらく時間をおいて再試行してください」
- その他: 「要約の生成に失敗しました」
- 内部詳細（モデル名、上流エラー本文）はUIに出さない
