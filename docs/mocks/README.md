# デザインモック（2026-07〜08）

`docs/IDEAS-2026-07.md` 第二部の5方向を、それぞれ単一HTMLで試作したもの。
`data.json` は凍結データ（2026-07-31 21:00 JST 採録）で、各モックはこれを fetch して描画する。
データにない事実の捏造はしない方針で作られている（詳細は各ファイル冒頭のコメント）。

| #   | ファイル               | 方向                                      | 採否                          |
| --- | ---------------------- | ----------------------------------------- | ----------------------------- |
| 01  | `01-control-room.html` | 管制室 — CRTレーダー・燐光緑・常時掃引    | 不採用                        |
| 02  | `02-broadsheet.html`   | 文芸版 — 新聞組版・AIが見出しを書く日刊紙 | **採用（メイン画面）** #31    |
| 03  | `03-greenhouse.html`   | 温室 — 植物のプロシージャル生成・実時間光 | 不採用                        |
| 04  | `04-night-radio.html`  | 深夜放送 — チューナーUI・speechSynthesis  | **採用（別画面 /radio）** #32 |
| 05  | `05-archaeology.html`  | 考古学 — 時間の川のドキュメンタリー上映   | 不採用                        |

## 閲覧方法

`fetch('./data.json')` を使うため `file://` 直開きでは動かない。ローカルHTTPサーバーを立てる:

```bash
npx serve docs/mocks
```

または `python -m http.server -d docs/mocks 8000` など。

- **01**: OSが動きを抑制していても `?motion=1` で掃引を強制起動できる
- **02**: 印刷CSS付き。実際に刷れる
- **03**: `?hour=23` のように時刻を指定して夜景・朝景を試せる
- **04**: 音が出る（speechSynthesis + WebAudio）。電源スイッチが再生開始の儀式
- **05**: 開いた瞬間に上映が始まる（約2分52秒）。終幕は管制室のライブ画面へ引き継がれる
